# ROYAL 車行管理系統

為朋友的機車行開發的 Windows 管理工具。有興趣的老闆歡迎下載，免費使用全部已提供功能輔助營業，也可以把完整官方版本免費複製給朋友一起用。

## 下載與開始使用

**[前往最新版下載頁](https://github.com/locksley1701/royal-motorshop-releases/releases/latest)**

1. 下載名稱為 `ROYAL-MotorShop-v版本-win-x64.zip` 的附件。
2. 將整份 ZIP 解壓縮到可寫入的資料夾，再開啟 `ROYAL-MotorShop.exe`。
3. 第一次可選擇「先用練習資料試操作」或「建立空白店務資料庫」。

不需要 Git、GitHub 帳號或產品金鑰。此處的 `Source code (zip)`／`Source code (tar.gz)` 只有本下載頁文件，請下載上面指定的程式附件。

## 提供的功能

- 客戶與車籍、保養工單、商品銷售及保養歷史。
- 商品分類、品牌型號、庫存進貨與盤點。
- 收款、欠款、退款、工單金額更正、退款日期補登及營運報表。
- 明細列印／PDF、M666 資料導入、本機備份及還原前差異預覽。
- 程式版本通知、系統設定內建一鍵更新與異常安全回退。
- 獨立教學練習區、51 門引導課程及隨點隨查的問號功能說明。
- 紙本日期補登、小螢幕布局與大型資料庫備份。

## 保存資料與更新

**最新版本 v0.9.14** 修正下載完成後按「確認更新並重啟」沒有後續動作的問題，更新失敗也會主動說明結果。**v0.9.13 及更早版本請先手動更新一次**：修正尚未安裝前，舊更新器無法自行修好。詳見 [新版下載與更新說明](https://github.com/locksley1701/royal-motorshop-releases/releases/tag/v0.9.14)。

資料預設存於程式旁的 **data** 資料夾；備份可另選其他位置。搬電腦或重灌前，先關閉程式，再複製完整程式與 data 資料夾。

1. 在舊程式確認資料儲存位置，儲存並關閉 ROYAL。
2. 將整個原程式資料夾另存一份備份；資料若另存在其他位置，也要完整備份。
3. 下載 `ROYAL-MotorShop-v0.9.14-win-x64.zip`，先解壓到暫存資料夾。
4. 將解壓後 **ROYAL-MotorShop-win32-x64 裡面的所有檔案及資料夾**，複製到原本 EXE 所在資料夾，選擇取代同名檔案。**保留原 data，不要刪除整個原資料夾。** 官方包不附 data。EXE 與 resources 必須一起更新，不可只換一個檔案。
5. 從原資料夾開啟程式，確認顯示 **v0.9.14**，再核對客戶、車輛與工單仍在。

若原資料在 AppData，請從舊程式顯示的位置複製完整資料資料夾至 EXE 旁的 `data`；新版不會自動搜尋。若明確設定 ROYAL_DATA_DIR，則維持原指定位置。看到初始化畫面但原本有資料時，先關閉程式並確認資料位置，不要重新建檔。完整步驟亦隨附於 ZIP 的「使用說明.txt」。

完成一次手動更新後，未來相容新版可由「系統設定 → 程式版本與更新」使用修正後的一鍵更新流程。下載完成不等於更新完成，重啟後請確認版本號。
