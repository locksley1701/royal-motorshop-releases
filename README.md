# ROYAL 車行管理系統

為朋友的機車行開發的 Windows 管理工具。有興趣的老闆歡迎下載，免費使用全部已提供功能輔助營業，也可以把完整官方版本免費複製給朋友一起用。

## 下載與開始使用

**[前往最新版下載頁](https://github.com/locksley1701/royal-motorshop-releases/releases/latest)**

1. 下載名稱為 `ROYAL-MotorShop-v版本-win-x64.zip` 的附件。
2. 將整份 ZIP 解壓縮到可寫入的資料夾，再開啟 `ROYAL-MotorShop.exe`。
3. 第一次可選擇「先用練習資料試操作」或「建立空白店務資料庫」。

不需要 Git、GitHub 帳號或產品金鑰。此處的 `Source code (zip)`／`Source code (tar.gz)` 只有本下載頁文件，請下載上面指定的程式附件。

## 提供的功能

- 客戶與車籍、保養工單、商品銷售及保養歷史。
- 商品分類、品牌型號、庫存進貨與盤點。
- 收款、欠款、退款及營運報表。
- 明細列印／PDF、M666 資料導入、本機備份及還原前差異預覽。
- 程式版本通知、系統設定內建一鍵更新與異常安全回退。

## 保存資料與更新

資料預設存於程式旁的 **data** 資料夾；備份可另選其他位置。搬電腦或重灌前，先關閉程式，再複製完整程式與 data 資料夾。

桌面版可直接從「系統設定」點擊「檢查更新」與「立即更新」，在背景完成下載並自動升級與備份；亦可按頂部「說明 → 檢查更新」前往下載頁手動解壓縮更新。手動更新時先關閉舊程式，把新版解壓縮到新的資料夾，再將原本完整 data 資料夾複製到新版程式旁。
